About these prices

TCGplayer market values are international/US-market references converted to PHP using a published FX rate. They are not guaranteed Philippine selling prices. Card condition, language, edition, printing, grading, shipping and local demand all affect value. Collectr integration is not included because an authorized public API connection has not been verified.
